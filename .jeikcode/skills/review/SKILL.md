# 🛡️ 画廊随想代码审查规范

## 1. 核心审查指标
1. **分包与体积红线**：禁止静态顶层引入 Monaco / Mermaid / 代码高亮，入口文件维持在 ~160 kB 极致量级。
2. **JSX 严格布尔计算**：严禁 `{item.top && <Badge />}`，必须显式三元运算 `{item.top > 0 ? <Badge /> : null}`，杜绝漏出数字 `0`。
3. **安全与密钥脱敏**：严禁提交真实 Token、秘钥或私有 IP；必须遵守 CSP Zero Eval 沙盒。
4. **命名与词汇合规**：严禁私有面板名词，统一使用“高密单屏超级数据表格”与“极简迷你侧边栏”等规范两字词汇。
