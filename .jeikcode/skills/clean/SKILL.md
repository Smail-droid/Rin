# 🧹 代码精炼与去油规范

## 1. 核心精炼准则
1. **纯文本主义**：能用纯文本两字流派分割解决的，坚决不生造彩色药丸胶囊或拼凑 Emoji。
2. **扁平逻辑控制**：使用卫语句（Guard Clauses）提前返回，杜绝三层以上的大嵌套。
3. **原子复用至上**：优先复用既有原子积木（`@rin/ui` 的 Modal、SearchableSelect、SettingsBadge），严禁增生一次性孤岛组件。
