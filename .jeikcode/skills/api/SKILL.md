# ⚡ API 与前后端契约设计规范

## 1. 契约设计铁律
1. **统一返回格式**：严格使用标准化 JSON 响应，成功返回 `{ success: true, ... }`，失败给出语义清晰的错误提示。
2. **边缘性能最优先**：禁止在大文件上传/下载接口中将数十兆文件转为 `arrayBuffer` 缓冲，元数据与实体二进制流隔离。
3. **鉴权与安全门禁**：管理员接口严格校验 Bearer Authorization Token，使用密码学安全的随机源与防重放机制。
