# 🔍 系统级根因排错执行指南

## 1. 根因排错四步法
1. **重现与假设**：明确故障发生的输入条件、环境差异（如文件体积、网络拦截、CORS、403 Token 异常）。
2. **边缘限制审查**：检查 Cloudflare Worker 运行内存（128MB）、子请求次数与 CPU 执行超时，防止大二进制文件在内存中反复缓冲引发隐性崩溃。
3. **架构级自愈设计**：不打脆弱补丁，优先采用独立元数据索引（如 `metadata.json`）等低损耗架构解决根本瓶颈。
4. **验证闭环**：通过全量测试用例（`bun run test`）与类型检查（`bun run check`）确保修复彻底无副作用。
