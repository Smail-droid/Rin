# 🌸 画廊随想 · 前端美化与外观治理章程 (Aesthetic & UX Charter)

> **定位**：本文件是画廊随想（Gallery Blog）所有前端视觉、主题配色、组件交互与前后台设置边界的**最高约束章程**。
> 任何后续功能迭代、样式重构或 Agent 自动修改，**必须严格遵守本文件全部条款**；未经站长明确修订本章程，严禁私自推翻布局范式、引入重复入口或破坏既有视觉不变量。

---

## 第一章：前后台权责与单一入口铁律 (Single Source & Zero Duplication)

1. **配置权责单一权威源**：
   - 所有完整的站点外观、版式、配色、背景、粒子、基础信息、安全开关、AI 与存储配置，统一收口于后台 **`/admin/settings`**，采用**分块直觉卡片、所见即所得**的排布方式。
   - **严禁**在前台页面堆砌多 Tab 大型侧滑抽屉（如 420px 多栏表单抽屉）或重复搬运后台管理表单。
2. **上方居中自然嵌入微工具栏（禁止底部悬浮胶囊）**：
   - 前台顶栏下方居中自然嵌入一条极轻量的文档流微工具栏（`TopAtelierRibbon`），采用统一 1.5px 精修线性 SVG 图标，**严禁使用右下角浮空阴影药丸遮挡内容**。
   - **访客与站长均可见 3 枚独立氛围开关与 4 大核心美学调控**：`樱花`、`细雨`、`萤火` 各自独立成钮，以及文章版式即切、画廊主题色盘即切、彩虹自由调色与 AI 导读现场总开关，访客在会话期间即时畅享外观自定义，博主管理态自动持久化至边缘数据库。
   - **管理员登录态**在同一条居中嵌入式工具栏中自然衔接：撰写/图床/音廊/标签体系直达中枢。
3. **同一视口日夜切换严格唯一**：
   - **前台**：仅保留顶部导航栏 1 处日夜模式切换按钮（支持系统/浅色/深色三档循环）。
   - **后台**：仅保留顶部控制栏 1 处日夜模式切换按钮。
   - **严禁**在侧边栏、悬浮轨、快捷栏或设置卡片内部再次重复放置日夜切换按钮。

## 第二章：画作原图完整与版式克制铁律 (Artwork Integrity)

1. **原图 100% 完整呈现，禁止强裁**：
   - **全幅沉浸画册 (`poster`)** 与 **拍立得瀑布流 (`default`)** 展示文章封面图时，一律采用自然原比例瀑布流（`w-full h-auto block`），**严禁写死 `aspect-[4/3]` + `object-cover`** 截断竖图、长图或宽幅插画。
   - 信息铭牌必须克制轻盈，不得大面积遮挡画作主体。
2. **4 套卡片版式结构清晰分明**：
   - `default`（拍立得瀑布流）：白边相纸 + 微倾角 + 多列瀑布流；
   - `poster`（全幅沉浸画册）：无白边满幅圆角 + 原图完整瀑布流 + 贴底轻磨砂铭牌；
   - `editorial`（图文双栏杂志）：单列宽幅左文右图 + 细线分隔 + 优雅衬线；
   - `compact`（紧凑文章列表）：单行日期/标题/时长高密扫读列表。
3. **首页标签纯粹洁净**：
   - 首页推荐标签保持纯粹的 `#标签名` 样式，**严禁**在标签右侧无故添加多余的跳转箭头图标（如 `ri-arrow-right-up-line`）。

## 第三章：首页便签克制与封面零遮挡铁律 (Subtle Sticky Artifacts)

1. **体量克制、绝不喧宾夺主**：
   - 便签是画廊的辅助导览挂件，视觉体量必须明显小于正文作品卡：
     - 长条卡片 (`card`) 保持紧凑内边距与精炼文案；
     - 圆盘挂件 (`circle`) 直径收敛在 `128px ~ 144px` (`w-32 sm:w-36`)；
     - 胶囊挂件 (`capsule`) 保持轻巧单行条；
   - 严禁在等高 Grid 布局中将便签拉伸成巨型方块。
2. **自定义封面图文字显隐策略（默认悬停浮现）**：
   - 当便签配置了自定义背景/封面图时，提供三档显式策略（字段 `atelier.<note>_text_mode`）：
     - **`hover`（悬停浮现 · 默认）**：常态 100% 纯净展示整张封面图，**0 黑幕、0 文字遮挡**；鼠标悬停时柔和浮现轻磨砂文字与引导；
     - **`hidden`（纯图无字）**：始终纯净展示封面图，点击整卡直达目标页；
     - **`always`（常驻显示）**：始终在封面底部轻渐变上展示文字。
   - 无封面图时正常展示清新纸面与文字。

## 第四章：明快通透配色与自由调色盘规范 (Color System & Palette Picker)

1. **明快清新的画廊主色与 18 套预设 + 自由调色盘**：
   - 保持画廊明亮清透的视觉气质（经典蔷薇樱落 `#fc466b`、和风青空 `#0ea5e9`、午夜深邃 `#6366f1`、薄荷苏打 `#14b8a6` 等 18 套鲜活预设），拒绝暗沉浑浊的“灰蒙蒙”低沉色块；
   - 后台 `/admin/settings?tab=theme` 必须保留 **18 套主题色珠 + 16 色高亮圆珠调色盘 + 彩虹原生自由取色器 + HEX 输入 + 卡片通透度滑块**，前台管理员顶部嵌入栏亦同步提供一键切换与彩虹自由取色器。
2. **暗黑模式极暗色保护**：
   - 仅对极度接近黑色的主题（如极简纸墨 `#27272a`）在暗黑模式下自动切换为清晰可见的提亮主色（`#6366f1`），避免按钮融进深色背景或出现浅灰底白字。
3. **纯净画布无默认脏光晕**：
   - 默认纯色画布保持纯粹干净（`body` 不叠加彩色径向光斑），仅在显式选择壁纸预设时才渲染轻盈纹理层。

## 第五章：氛围粒子确定性原则 (Deterministic Ambience)

1. **持久化站点配置**：
   - 粒子模式由 `theme.ambience`（`"none" | "sakura" | "rain" | "fireflies"`）统一持久化驱动，支持在后台设置与管理员前台一键循环即时生效。
2. **手动开启必渲染，严禁静默失灵**：
   - 一旦站点或用户显式选择了非 `"none"` 的粒子模式，Canvas 画布**必须立即启动动画并可见渲染**，严禁因操作系统动画偏好（`prefers-reduced-motion`）静默跳过导致“点了毫无反应”。
3. **明暗双模式清晰调校**：
   - 樱花、细雨、萤火均需针对浅色与深色画布分别调校色彩饱和度与透明度，确保肉眼清晰可辨又不遮挡阅读，且 `pointer-events: none` 永不拦截页面交互。

## 第六章：系统联动与组件复用铁律 (System Cohesion)

1. **统一画廊留言板组件**：
   - 文章详情页与「日常随想 (`moments`)」等全站互动模块，**必须共用统一的画廊留言板核心组件**（`UnifiedCommentComposer` 与 `UnifiedCommentItem`）。
   - 登录用户（含站长）自动继承当前登录身份与头像，**无需手动填写昵称**；访客自动分配二次元萌系昵称与专属头像（支持一键随机切换），并提供宽敞舒适的多行 Markdown 编辑框与统一的外链风控审核流。
   - **严禁**在不同页面各自手搓简陋的单行输入框造成体验割裂。

---

## 第七章：粒子智能避障与生机拟物原则 (Smart Particle Avoidance & Atmosphere)

1. **正文阅读区智能避障**：
   - 全视口动态氛围粒子（樱花、细雨、萤火）必须智能感知当前文章核心阅读容器（`article`、`.markdown-content`），**严禁粒子在阅读区域穿行遮挡文本**：
     - **樱花**：接近正文时施加平滑横向斥力，向两侧留白边缘自然偏转；落在正文核心区时柔和淡出至不可见；
     - **细雨**：落点位于文章阅读区内时不予绘制，营造“窗外细雨朦胧、室内静心阅读”的清爽意境；线条细化为 `0.7~1.1px` 纤细雨丝，速度放缓 50%；
     - **萤火虫**：色谱升级为 555nm 真实萤火虫黄金磷光（绿幽幽玉色辉光），采用双相位 $\sin^2$ 脉冲呼吸曲线，呈现真实的明暗交替与夜光生物微闪。

## 第八章：前台创作工坊与手账便签美学 (In-Situ Atelier & Sticky Artifacts)

1. **便签杜绝 Emoji 杂色，统一典雅微光矢量图标**：
   - 全站便签一律使用 Remix Icon 纯矢量线性图标（如 `ri-user-smile-line`、`ri-planet-line`、`ri-chat-heart-line` 等），**严禁使用 Emoji 表情作为便签默认图标**；
   - 列表模式（`compact`）下，便签专属应用 `border-2 border-dashed border-theme/35 dark:border-theme/30 rounded-2xl` 虚线圆角手账样式，与实线列表形成鲜明美学反差；
   - 便签支持与画廊文章自由跨界位移，并在设置弹窗中提供一键与任意指定文章直接对调。
2. **前台微光工坊与轻量照片胶卷**：
   - 撰写文章图库选图采用非阻塞式水平照片胶卷（Recent Photos Filmstrip），点击直接展开 48px 紧凑横向胶卷，点选即刻就地插入，**严禁使用全屏黑幕大弹窗遮挡博主写作视线**；
   - Markdown 工具栏实行单行精炼分组，高频键直接保留，次频排版工具收拢至「更多」下拉菜单，彻底杜绝折行变两排；
   - 音廊曲库（`/music`）与图床画廊（`/gallery`）全面融入前台路由，访客与管理员权限严格分层（访客只读与播放、删除操作严格物理锁定）。

---

## 第九章：视觉变更自检门禁 (Verification Gate)

每次涉及前端外观、配色、版式或特效的变更，提交前必须完成：
1. `bun run check` 零类型报错；
2. `bun run test` 全量测试 100% 通过（包含色盘明暗对比度断言）；
3. `bun run build` 守住首屏分包底线，重型库（Monaco、Mermaid）保持动态按需异步加载；
4. 无头浏览器实测亮/暗双模式渲染、原图宽高比未裁切、粒子 Canvas 非空帧渲染与同一视口无重复日夜按钮。
