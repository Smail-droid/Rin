# 🌸 画廊随想 · 前端美化与外观治理章程 (Aesthetic & UX Charter)

> **定位**：本文件定义画廊随想（Gallery Blog）前端视觉系统的**架构不变量、组件权责边界与可配置设计协议**。
> **核心原则**：**只定架构原则与可控维度，绝不把具体配色、字体或单一版式写死**——任何后续调色、换字体、新增风格预设或组件重构，只要遵守本协议的“真实生效、边界清晰、全站同步、可用性兜底”原则，均可平滑演进，绝不受历史硬编码教条束缚。

---

## 第一章：单层极简导航与前后台权责边界 (Single-Row Header & Studio Boundaries)

1. **前台极简单层顶栏（告别多层工具条堆叠）**：
   - 前台顶部**仅保留 1 行**轻盈融入式主导航栏（支持后台配置真实差异化的布局形态：`classic` 居中自然、`compact` 极简纯文本、`dock` 三岛悬浮微光）：
     - **左侧**：站点 Logo 与品牌名；
     - **中间**：全站核心页面导航（文章、时间轴、动态、标签、星廊、关于及可选挂载入口）；
     - **右侧**：全局工具组（站内检索、`🎨 外观` Popover 轻量入口、唯一日夜模式切换、多语言及用户头像菜单）。
   - **禁止在顶栏下方常驻二/三层全局工具条**：不再让仅属于某一个页面的开关或仅属于站长的操作钮污染全站所有页面的首屏空间。
2. **就地分级收纳（Progressive Disclosure by Role & Scope）**：
   - **全局 `🎨 外观` Popover（右上角轻量气泡）**：面向所有访客与站长，收纳高频且作用于全站的轻量调控（氛围粒子特效、精选主题方案、阅读字族/字号），平时收起零视觉噪音。
   - **管理员 `头像▾` 下拉菜单（及后台独立侧栏）**：收纳站长专属快捷入口（撰写工坊、云端图床、微光音廊、标签表格、**AI 助手 (`/admin/ai`)**、系统设置与概览），访客界面保持绝对洁净。
   - **页面本地动作区**：文章版式切换、导读开关、文章/草稿/未列出切换、首页标签恢复等**首页专属控件**，下放回首页内容区 `<PageHeader>` 右侧；全站依赖常驻顶栏回主页，不在子页重复堆砌返回按钮。
3. **后台控制中枢、独立 AI 助手与非阻塞反馈**：
   - 站点级细粒度组件化定制收口于 **`/admin/settings`**（采用 **Bento Grid 模块化卡片 + 所见即所得预览**，拒绝单调全宽单行长条堆砌与“点抽屉再跳后台”的多余中转）；
   - **`/admin/ai`（AI 助手）**必须在后台导航侧栏常驻直达，统一前后台配置键（`ai_summary.*`）、支持服务端多协议适配（OpenAI / Claude / Gemini / Worker AI）、自动模型列表拉取与提示词库持久化；
   - **常规保存零弹窗打扰**：正常保存、复制或更新动作直接在按钮原地切换状态（`保存中…` → `✓ 已保存`）或弹出非阻塞轻量 Toast；**阻塞式确认弹窗仅用于真实报错或不可逆删除二次确认**。
4. **同一视口日夜切换严格唯一**：
   - 前台顶栏仅保留 1 处日夜切换按钮，后台顶栏仅保留 1 处日夜切换按钮，严禁多处重复出现。

## 第二章：统一 `<PageHeader>` 与全站版心对齐 (Unified Page Header & Grid Alignment)

1. **三段式展览画册页头原语 (`PageHeader`)**：
   - 全站主页面（画廊随想 `/`、时光长河 `/timeline`、日常随想 `/moments`、标签索引 `/hashtags`、星标友链 `/friends`）统一复用同一套页头架构与一致的容器最大宽度（默认居中标准版心或配置化宽度，保证页头与下方列表/网格**左右严格对齐**）：
     - **轻量大写英文眉标 (Eyebrow)**：例如 `GALLERY ESSAYS · 22`、`CHRONICLE`、`MOMENTS` 等，营造独立画廊刊物感；
     - **人文主标题 (`H1`)**：接入全局正交组合的标题字族与字效系统；
     - **柔和副标题 + 右侧本页动作槽位 (`actions`)**：按页面需要挂载本地切换器或操作按钮。
2. **后台与媒体工作台秩序（借鉴 BentoGrids / DesignSpells / Refero）**：
   - 优先使用 **Bento Grid 模块卡片**、**DesignSpells 式清透展框**（细描边 + 轻质外置元数据，避免粗黑遮罩与孤立灰框）及 **Refero 式静谧左侧栏 + 宽裕工作区**；
   - 标签索引、星标友链等筛选区保持秩序清晰（搜索与分段切换、紧凑操作栏、底部分页脚），不强行把所有界面都做成高密表格，亦不把筛选与新建控件拆散在 4~5 个角落。

## 第三章：真实有效的语义设计令牌与正交系统 (Composable Design Tokens & Orthogonal Typography)

> **去空壳铁律**：禁止只改名字、不改实际视觉效果的“假预设壳子”。每项预设与自定义滑块必须直连真实 CSS 变量并在全站同步生效。

1. **四层联动语义表面令牌 (Semantic Surface Tokens)**：
   - 所有主题方案（包含温润低饱和纸感默认方案如「樱雪纸墨」`#FDFBFC` / `#D87A90` / `#2D2628`，以及「暖麦护眼」「经典蔷薇」「和风青空」「午夜深邃」等，方案集合可平滑扩展）必须完整映射：
     - **画布底色 (`Canvas`)** & **卡片表面 (`Surface`)** & **弹出浮层 (`Elevated`)**；
     - **墨色文本阶梯 (`Ink Primary / Secondary / Muted`)**；
     - **发丝描边 (`Hairline`)** & **主强调色 (`Accent / Accent-Soft`)**：浅/深双模式下所有按钮与文字配比满足 WCAG AA 对比度（≥ 4.5:1）；
   - **表单隔离**：严禁对 `<input>` / `<textarea>` 等表单元素套用带强阴影和毛玻璃模糊的容器类。
2. **非阻塞字体与正交 `字族 × 质感` 标题系统**：
   - 正文与标题字族解耦：支持现代无衬线、思源宋体（人文画廊风）、霞鹜文楷（温润手账风）及等宽极客字族；外部字体采用非阻塞异步按需加载 + 系统优雅回退；
   - 标题效果与字族正交可调（如 `字族` × `纯墨极简 / 柔和微光 / 刊号细线 / 复古压印 / 霓虹微闪`），每档组合肉眼清晰可辨。

## 第四章：画作完整性、跨页组件审美与权限隔离 (Artwork, Cards & Cohesion)

1. **画作原图 100% 完整呈递与防塌陷**：
   - 全幅沉浸画册（`poster`）与拍立得瀑布流（`default`）展示封面时，统一采用原图自然比例（`w-full h-auto block`）与尺寸/BlurHash 占位，禁止强裁作品封面或加载期塌陷；
   - 拍立得标题落位底部相纸留白区；图文杂志（`editorial`）始终展示摘要与纯标签；紧凑列表（`compact`）保持高密扫读、纯标签与轻预览。
2. **首页便签克制区分与封面策略**：
   - 便签体量明显小于正文作品卡，并在材质上（如极淡主题磨砂底 + 1px 虚线边）与文章卡区隔；配图便签默认遵循“悬停浮现文字（`hover`）”，常态零遮挡；首页推荐标签保持纯粹 `#标签名` 样式。
3. **星廊友链、留言板与详情页质感**：
   - 友链解除 40 字硬截断限制（支持完整简介展示如 160+ 字），默认提供「横版精致名片卡（左图标+右信息+单行紧凑节点指标）」，同时支持柔和渐变画廊卡与紧凑书签行切换，外链头像失效平滑降级为首字徽章；
   - 文章详情页与动态页统一复用 `UnifiedCommentComposer` / `UnifiedCommentItem`；详情页首图与正文开头相同图片自动去重；全站统一精致线性矢量图标。
4. **Navidrome 级音廊与画廊图床工作台**：
   - `/music` 对标 Navidrome 专业专辑封面墙 + Refero 静谧左侧栏 + 底部一体播控 + 音轨表切换；`/gallery` 提供相册目录侧栏 + 单行工具栏 + 原比例瀑布流/图格切换 + 非阻塞复制/检查面板；
   - 访客态严格只读与试听，管理员写删控制物理隔离。

## 第五章：氛围特效与组件级演进原则 (Deterministic Ambience & Motion)

1. **氛围粒子确定性渲染与阅读避障**：
   - 显式开启非 `"none"` 粒子（樱花/细雨/萤火）时必立即启动可见渲染，不受 `prefers-reduced-motion` 静默跳过，并避开核心阅读区域，明暗双模独立调校。
2. **弹幕与全局浮件克制联动**：
   - 弹幕保持低饱和柔和质感并支持开关；浮动音乐播放器维持清晰磨砂底盘与安全边缘停靠；暗黑模式背景渐变自动限制低透明度上限。

## 第六章：视觉变更闭环验收门禁 (Visual Verification Gate)

任何涉及外观、令牌、版式或跨页组件变更，交付前必须完成：
1. `bun run check` 0 报错、`bun run test` 全量通过、`bun run build` 重型库保持异步分包；
2. 关联页面影响面自查（确认修改共享组件、令牌或路由不会顾头不顾尾，版心对齐与权限隔离严格有效）；
3. **轻量克制验证原则**：杜绝盲目全站重复截图（防止过度消耗上下文与触发限流）；以测试套件断言与代码契约为第一防线，仅在用户明确需要或特定疑难时进行单点轻量核验。
