# ADR-0001: 边缘原生微世界插槽架构与技能自治体系演化 (Micro-World Cartridge & Skill Autonomous Governance)

- **状态 (Status)**: 已接受 (Accepted)
- **日期 (Date)**: 2026-11-14
- **主导决策者 (Deciders)**: 博客系统缔造者与全栈 Agent 核心协同小组

---

## 1. 背景与核心冲突 (Context & Tension)

画廊随想（Gallery Blog）最初的初心是**“一页一世界”**：构建一座基于 Cloudflare 边缘原生生态（Workers + D1 + R2 + Pages）的自托管微服务矩阵（包括独立的图床存储、音廊播放器、探针测速监控、星标画廊圈等）。博客本身仅仅是承载这些灵感与世界航海日志的“观测站与展示透镜”。

然而在长期的迭代与日常维护中，系统陷入了经典的技术债务泥潭：
1. **单体紧耦合与架构失控**：原本期望像插拔卡带一样自由接入的图床、音廊、友链等模块，逐渐与核心 SPA 路由、主表数据模型和硬编码样式紧密交织，新增或移除一个模块需要修改十余处代码；
2. **人肉维护与灵感耗竭**：开发者被迫承担繁重的“肉体测试员”角色（手动刷新页面排查破图、403、边距空旷），并在高强度编码后还要人肉编写与排版博文，导致极度疲惫与失控感；
3. **陷入局部死胡同**：AI Agent 往往沦为“头痛医头、脚痛医脚”的防御性修 Bug 机器，偏离了缔造可自由拼装微世界的最初构想。

---

## 2. 演进路线图决策 (Decision Sequence: Q4 ➔ Q2 ➔ Q1 ➔ Q3)

为了从根本上扭转失控局面，我们裁决依序推进四大演化支柱：

```text
[Q4 技能与架构守门] ➔ [Q2 灵感开发纪事] ➔ [Q1 微插槽卡带架构] ➔ [Q3 视觉原子设计系统]
     (规范与自治)          (记忆与沉淀)          (模块与解耦)          (自由组合表达)
```

### 支柱一：Q4 技能自治与架构守护者 (Autonomous Skills & Architecture Guardrail)
1. **自然语言完全驱动**：彻底终结开发者手动输入斜杠指令的旧习惯。Agent 具备自主意图感应中枢，按需无感调取对应技能；
2. **架构偏航主动拦截**：Agent 必须充当架构守门人。凡是破坏模块解耦原则、引入全局硬编码依赖的临时修补，Agent 必须主动叫停并提供接缝隔离方案；
3. **自主浏览器闭环自检**：Agent 必须调度 Puppeteer 无头浏览器与真实 DevTools 审查 DOM、网络瀑布流与视口渲染，自闭环自验，严禁将开发者当成测试员。

### 支柱二：Q2 灵感与开发纪事自动化 (Dev Chronicle & "Session-to-Feed")
1. **会话即纪事**：每次完成模块设计或重大特性推演，Agent 自动调用文本提炼管线，将对话构思与架构决策整理为高质量 Markdown 开发手记并沉淀入库；
2. **页面内嵌「诞生初衷」透镜**：每一个独立世界的角落（如音廊顶部、星廊角标）内嵌一个极轻量的「诞生灵感」透镜原语，点击即可调起该模块的设计手记与演化背景。

### 支柱三：Q1 微插槽卡带架构 (Micro-World Cartridge Architecture)
1. **标准卡带契约 (`@rin/cartridge`)**：每个功能世界定义为独立卡带（Cartridge），包含：
   - `manifest`: 包含世界名称、图标、路由挂载点、外部依赖声明；
   - `service`: 独立的边缘路由 Handler，零污染主站核心表；
   - `view`: 前端插槽卡片与主视图组件；
2. **母舰总线（Ship Base Bus）**：主博客仅提供统一的身份、持久化总线和导航卡槽，对卡带实现“即插即用、自由拔插”。

### 支柱四：Q3 视觉原子设计系统 (Design Tokens & Visual Sovereignty)
1. **设计变量白盒化 (Design Tokens)**：将主题色彩、网格列数密度（高密单屏/宽幅画册）、卡片材质（拍立得纸质、毛玻璃亚克力、极客终端）全面参数化；
2. **决定权完全归还**：用户不仅是在被动使用样式，而是在控制台自由拼装组合自己期望的质感。

---

## 3. 影响与收益 (Consequences)

- **积极影响**：
  - 开发者的心智负担大幅降低，不再需要记忆繁杂指令，无需在编码后强迫人肉写文；
  - 模块边界清晰严密，新增自托管服务（如短链服务、剪贴板、监控探针）只需编写独立卡带文件并接入总线，零副作用；
  - 质量门禁与端到端真实渲染由 Agent 自主在后台完成验证。
- **治理约束**：
  - 严禁任何子模块擅自跨卡带访问内部实现细节，必须严格通过预定接缝（Seam）通信。
